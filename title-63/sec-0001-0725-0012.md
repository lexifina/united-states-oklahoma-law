# §63-1-725.12. Hospitals - Public lists of standard charges.
Notwithstanding any other law, a hospital shall make public:
1. A digital file in a machine-readable format that contains a list of all standard charges for all hospital items or services as described by Section 3 of this act; and
2. A consumer-friendly list of standard charges for a limited set of shoppable services as provided in Section 4 of this act.
