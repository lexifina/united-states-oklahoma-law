# §47-12-503. Prohibited acts.
No person shall:
1. Advertise for sale, sell, use or install or cause to be installed or request for installation, any device which causes an odometer to register any mileage other than the true mileage driven; 2. Disconnect, reset or alter, or cause or request to be disconnected, reset or altered, the odometer of any motor vehicle with intent to change the number of miles indicated thereon;
3. Knowingly operate a motor vehicle with a disconnected or nonfunctional odometer on any street or highway with the intent of misrepresenting the true mileage driven; and
4. Conspire with any other person to violate any section of the Odometer Setting Act.
